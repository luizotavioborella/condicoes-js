# 🔀 JavaScript Conditions

A collection of exercises developed with HTML and JavaScript to practice conditional structures and basic programming logic.

These activities were created during the Systems Development course at SENAI to reinforce the use of `if`, `else if` and `else` in different situations.

## ✨ Exercises

The repository contains exercises involving:

- Comparing two numbers
- Even and odd number verification
- Age verification
- Student approval verification
- Positive, negative or zero number verification
- Password verification
- Purchase discount calculation
- Day of the week identification
- Leap year verification
- Finding the largest among three numbers
- BMI calculation and classification
- Discount based on payment method
- Greeting based on the time of day
